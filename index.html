SmartCart: el carretó intel·ligent

Una experiència de compra personalitzada que identifica productes, filtra al·lèrgens i preferències alimentàries i guia l'usuari pel supermercat.

Veure el prototip Veure documentació
El repte de la compra

Una compra més accessible, segura i personalitzada

Trobar productes adequats entre milers d'opcions pot ser complicat per a persones amb al·lèrgies, intoleràncies, celiaquia o necessitats dietètiques específiques. A més, localitzar els productes d'una llista de la compra requereix temps i informació que sovint està dispersa.

La nostra solució: un carretó intel·ligent amb pantalla i lector de codis de barres, connectat al catàleg del supermercat, que filtra productes segons el perfil de l'usuari, recomana alternatives i indica on trobar-les.
Funcionalitats del producte

Arquitectura i funcionalitats clau

Un sistema modular que integra productes, preferències alimentàries, inventari i navegació dins del supermercat.

Hardware Estructura
Carretó i pantalla interactiva

Carretó equipat amb una pantalla tàctil, suport per al dispositiu d'escaneig i una interfície senzilla per consultar productes, llistes i recomanacions.

Escaneig Codis de barres
Escàner i electrònica

Lector de codis de barres i unitat de control que identifiquen els productes i connecten la pantalla amb el sistema de dades del supermercat.

Software API / Base de dades
Base de dades i recomanacions

Sistema que relaciona cada producte amb ingredients, al·lèrgens, informació nutricional, disponibilitat i ubicació, i proposa alternatives segons els criteris seleccionats.
